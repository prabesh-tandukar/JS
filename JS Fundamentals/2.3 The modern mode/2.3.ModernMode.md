# The modern mode, "use strict"

### "use strict"

The directive looks like a string "use strict" or 'use strict'. when it is located at the top of a script, the whole script works the "modern" way. Eg:

```javascript
"use strict";

//this code works the modern way
```

We can use "use strict" on the beginning of a function only. Doing that enables strict mode in that function only. But usually people use strict mode for the whole script.

```javascript
//Make sure that "use strict" is at the top of the scripts, otherwise strict mode may not be enabled.

//Strict mode isn't enabled here:

alert("some code");
//"use strict" below is ignored -- it must be at the top

("use strict");

//strict mode is not activated

//Only comments may appear above "use strict"
```

### Should we "use strict" ?

Modern JavaScript supports "classes" and "modules" - that enable use strict automatically. So we don't need to add the "use strict" directive, if we use them.
